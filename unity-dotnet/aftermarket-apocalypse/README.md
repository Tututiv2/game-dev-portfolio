# Aftermarket Apocalypse

A round-based zombies survival shooter in Unity 6 (URP), with a serial-numbered cosmetic skin economy on top.

The core is classic round-based zombies: doors you buy open, a power switch that wakes the map, boarded windows to rebuild, wallbuys, a Mystery Box, perks and Pack-a-Punch. On top of it sits a cosmetic economy of skins with float wear and serial numbers, opened through an animated reel with published odds. This repository is a clean rebuild driven by a written spec, with the map, machines and content built by editor tooling rather than by hand where possible.

## Features

- Two maps: Ashfall Depot (hand-dressed) and Ashfall Metro (6 zones, 7 doors, 8 barriers, 5 perks, Pack-a-Punch, generated from a table of rectangles)
- Buyable doors, power switch with a light cascade, 7 boarded windows (+10 Essence per board rebuilt)
- 3 wallbuys, 2 relocating Mystery Boxes, 5 perk machines, Pack-a-Punch, Ammo Crate and Gobblegum machine
- Round director, zombie AI on a baked navmesh, ragdolls, HUD, pause menu, power-ups
- Skin economy: drop tree with pity, float wear, serials, an opening reel, store with published odds, collection screen
- Theme system: an HSV Recolor shader with three mask regions, 14 themes and 7 playable characters
- All input through the new Input System; legacy `UnityEngine.Input` is disabled

## How it works

- **Maps built and verified by tooling.** `MapPlan` describes a map as rectangles on a 4 m grid and derives the walls. `MetroVerify` checks reachability and counts vertex-disjoint routes with max-flow, because a map with no loop is unplayable past round 10 and no screenshot shows it. The first Metro layout scored 1 route with 230 tests green; it now has 2.
- **Tests that guard whole classes of bugs.** 213 EditMode and 11 PlayMode tests pass. One scans runtime source and fails if anything reads the legacy input manager. Another fails the build if retired currency or loot-box names reappear. PlayMode tests measure where the reel actually lands, open a real Sacred through the backend, and time a bulk bundle to prove skip-to-summary is honoured.
- **The reel is theatre over a known outcome.** The backend's roll, pity, serial allocation and mint all happen first, behind an `IBackend` interface; the animation never decides the item. Published odds are post-pity (the top tier is 1 in 100 by design, not the 1 in 8,000 of the raw tree), and the disclosure is computed from the same constants as the drop table.
- **Measuring instead of eyeballing.** A weapon skin was first built as a generic rifle with the reference art projected onto it, which looked right side-on and was the wrong shape. `check_silhouette.py` renders an orthographic side view and reports IoU plus a per-station difference in millimetres; it also exposed a 6.66 degree misregistration in the projection. Every outline is now measured off the reference (IoU 0.76 at 87% coverage).
- **Tuning lives in code.** Numbers live in `RoundRules` and `DamageMath` instead of inspector fields, which removes a class of bugs where a scene silently ran different values from its script.

## Tech

C# / Unity 6000.3.1f1, URP, Input System, ProBuilder, AI Navigation, Shader Graph (generated by a Python script), Unity Test Framework. Python tooling for Blender module cutting, texture and mask generation, and a ComfyUI/Hunyuan3D prop pipeline.

## Running it

- Open the folder in Unity Hub with **Unity 6000.3.1f1**.
- Builders live under `Tools > Aftermarket` (for example *Build Everything*, *Build Store*, *Build New Map (Ashfall Metro) - EVERYTHING*).
- Run the tests headless:

```
Unity.exe -batchmode -nographics -projectPath . -runTests -testPlatform EditMode -testResults TestResults.xml
```

**What is included:** `Assets/_Project` code, scenes, prefabs and tests, `ProjectSettings`, `Tools/`, and design docs in `docs/` and `REBUILD_SPEC.md`. **What is not:** `Assets/_Project/Art` and other Asset Store content (characters, zombie, materials, weapon packs), which are licensed and not redistributable, plus `Library/` and build outputs. Expect missing art references in scenes and prefabs.

**Status:** phases 1-7 and the visible half of the skin economy are done. Trading and phases 9-12 are not built.
