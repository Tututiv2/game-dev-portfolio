Tab volume boost

Same kind of boost as other Chrome “volume” extensions: Web Audio multiplies the sound from this page’s media before it leaves the browser. This does not raise Windows for Spotify.exe, games, etc.

Level (0–1000%) 100%

100% = unchanged. 200% = 2× amplitude (louder, may clip). Reload a tab if a site already started audio before the extension loaded.

Brave users: load unpacked in brave://extensions (not chrome://). If a site is still at normal volume, use the Shields (lion) menu → lower Shields for that site, then refresh — strict fingerprint blocking can break Web Audio. Also try a normal reload after changing the slider.

For local file:// pages, turn on “Allow access to file URLs” in brave://extensions or chrome://extensions.
