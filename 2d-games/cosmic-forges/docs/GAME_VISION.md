# Cosmic Forges — game vision

Industrial space fantasy: climb from a single world to **planets → solar systems → galaxies → universes → multiverses → dimensions** through data-driven systems and **tiered simulation** (tactical, strategic, meta, transcendent), not a single monolithic 3D simulation of everything.

**Phase 0 (current)** is a **vertical slice**: one ore resource, an extractor buildable, a timed enemy wave, core HP, deterministic tick + save/load. Later phases add pollution, FTL, megastructures, and endgame "law" tech per the [master prompt](MASTER_PROMPT.md).

**Tone**: hard sci-fi meets incremental ascension. Factorio-style pressure: waves evolve with your footprint; logistics bottlenecks matter at every tier where belts or routes exist.

**Lore (stub)**: the **Primordial Lattice** underpins all dimensions; you harvest ferrium, stabilize branes, and eventually negotiate or break multiversal parity—details TBD in design passes.

**Tech tree (future)**: soft-gated web, not a single trunk; see Phase 1+ implementation notes in [AGENTS.md](../AGENTS.md).
