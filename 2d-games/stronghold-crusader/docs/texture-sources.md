# Texture Sources (License-Friendly)

Use these for real production textures:

- [Poly Haven](https://polyhaven.com/textures) - CC0, high quality PBR textures.
- [ambientCG](https://ambientcg.com/) - CC0, large free library.
- [Kenney Assets](https://kenney.nl/assets) - game-ready stylized packs (check per-pack license notes).
- [OpenGameArt](https://opengameart.org/) - mixed licenses; verify attribution/share-alike terms.
- [Itch.io Asset Packs](https://itch.io/game-assets/free/tag-textures) - mixed licenses and styles.

## Quick Licensing Rules

- Prefer **CC0** sources for easiest commercial use.
- Keep a small `THIRD_PARTY_ASSETS.md` in your repo noting source + license for each imported pack.
- If license requires attribution, place credits in game credits + repo docs.
