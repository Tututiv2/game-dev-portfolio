Prefab editor

Click a part to select it, then use the gizmo to move, rotate, or scale. Curve bend (cylinder) below bakes a smooth bend into multiple cylinder pieces (good for axe handles). Saves to LT2_PrefabEdits. Use Tree (default wood), Tree (Spook wood), and Tree (void / purple neon) in the kind list for separate previews (void trees in the game use the treeVoid mesh when saved, otherwise they fall back to tree). Plank (classic wood) and Plank (Spook / neon) match simple-sawmill plank looks for reference (the game still builds planks procedurally when you cut logs). The game reads conveyor, shelf, and simple sawmill (sawmill prefab key) when those prefabs are saved. Starter axe (first-person) (axe): with no saved JSON for this kind, the editor loads models/files/axe.obj + the PNG next to it (no MTL required). The main game uses the same OBJ for the held axe. Use ＋ New prefab… for a custom prefab key.

Belt speed — multiplier on in-game push along the belt (saved with this prefab; reload map / restart game to apply).
Plank convert zone — cyan box: axis-aligned volume in sawmill local space where the whole log (including length) must fit to convert (+X = front). Not exported as mesh; saved on Save. Invisible in-game. If long logs never cut, widen X min / X max or click Reset for the new wider defaults.
Crown — thick columns grow from the top of the main trunk (not separate mesh parts). Min / max = how many columns (2–6). Twigs = small side branches per column. Preview seed saved on Save; in-game layout uses map position.
Spook wood glow — neon color + emissive + selective bloom in the game (saved to LT2_NeonTreeSettings). Prefab preview bloom applies on kind Plank (Spook / neon).
Curve bend (cylinder) — select a cylinder part, set angle + segments, then bake. Replaces it with several shorter cylinders along a Catmull–Rom spline (still normal prefab JSON).

Bend is baked into more primitives (not a live Blender-style modifier).
