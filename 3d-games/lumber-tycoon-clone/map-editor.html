Map editor

The JSON field defaultPlanetId is whichever planet is selected here when the map saves — the game loads that world’s slice until in-game planet switching exists.

How saving works: Save now and auto-save write to this browser’s storage (not a file on your drive). To keep a copy on disk, click Download .json — that saves lumber-map.json in your Downloads folder. Use Import .json to load it back after clearing storage or on another PC.
In the actual game the green sell ring, placed props (slab, block, strip, conveyor), chat labels, land plots (Bob’s purchasable lots — plotSites in JSON), and trees (new game) load from this map. The shop interior (Bob, Rob, shelves, counter) still comes from game code. If you define no land plots, the game falls back to four default lots.

The shop preview (walls, dock, Bob) matches the game visually. The bright green ring is the sell zone — click it (without Shift) to move or scale it. Use Stretch to resize the sell radius. Shift+click ground places trees/props. Gizmo appears only after you click an item again (not right after placing). Orbit by dragging. Delete removes selection (sell zone cannot be deleted). Ctrl+Z undo · Ctrl+C copy selection · Ctrl+V paste (offset). Ctrl+click conveyors to multi-select and batch-rotate belt direction. F2 edits chat text or lot name when a label / land plot is selected.

Terrain — procedural heightmap saved in map JSON as terrain (hides flat grass preview here; the game matches this mesh visually). Physics still use a flat ground until planet/collision work lands.
