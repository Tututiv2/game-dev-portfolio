The Still · production plan · phase 0 through 10

How To
Actually Build It

Eleven phases, each with a gate — a condition that has to be true before the next one starts. The gates matter more than the phases do. Most servers die because somebody built phase 7 while phase 2 was still not fun.

Presentation is not a final phase. It's a parallel track that ships a little in every phase, because a server that looks like default Minecraft for eight months has no players left to show the good version to.

Build these once, early — or retrofit them four times

Region abstractionPhase 0

Din spawn pressure, room heat, PvP flags, the Ledger and steam rendering all ask the same question: which shaft is this block in? Build one region system with fast lookup and per-region key-value state. Everything else hangs off it. Getting this wrong is the single most expensive mistake available to you.

Scoreboard slot registryPhase 1

Don't write a scoreboard — write a system where any module registers a line with a priority and a live supplier. Then Din, heat, Pitch, bounty and Wake each add themselves in one line of code when they're written. Retrofitting a hardcoded scoreboard eight times is misery.

Colour & gradient enginePhase 3

Needed first for perimeter lamps, then reused by nametags, chat themes, bossbars, scoreboard accents, the Wake and every cosmetic you ever sell. Write it once as a real library — hex, multi-stop gradients, per-character animation, tick-driven phase offset.

The PDC band stampPhase 2

Stamp the Din band and heat state onto the item at break time. If the multiplier is applied at sell time, players bank at CHOIR and cash out safely in the morning, and the entire design is dead. This is one line and it is load-bearing for the whole game.

Config registration as you goEvery phase

Your own law says every dial gets a GUI. Make registration part of writing the dial, not a phase-10 cleanup. A dial that isn't in /config the day it's written never gets added.

00Foundation

The Skeleton

A plugin that persists player data and has never once lost any.

Systems

  • Composition root. One plugin class, one place where everything wires together. Copy the shape of GamePlugin.java — it's the thing about Shadow Prison that most obviously works.
  • Player profile + async persistence. SQLite with a connection pool. Write-behind with a flush interval, plus a forced flush on quit and on shutdown.
  • Config system with hot reload, typed accessors, and defaults that can't be null.
  • Command framework with permission nodes, tab completion and a shared GUI builder. You will write 100+ commands. Build the framework first.
  • Region abstraction. Fast block→region lookup and arbitrary per-region state. See above. Do not skip this.

Presentation

  • None. Resist. The only visible thing this phase ships is a join message, and only so you know the plugin loaded.

Gate

Kill -9 the server mid-session, ten times, at random moments. Zero data loss, every time. If you can't say that out loud, you are not past phase 0.

Playable

Nothing. That's correct.

Scope · 1–2 weeks

01Spine

A Boring Prison Server

Mine, sell, rank up. Complete and completely unexciting — which is exactly what it should be at this stage.

Systems

  • Depths D1–D26 as regions with ore tables. Keep Shadow Prison's structure — filler weight 75, ores totalling 25 — because it's already tuned and you know it works.
  • Mine reset scheduler. Percentage-triggered plus a time cap, with a safe player eject.
  • Economy. Balance, /sell, /sellall, /sellallfilter, per-material price map with a custom-item override layer.
  • Rank ladder. /rankup, costs $0 → $1.4M, permission-gated depth access, a rankup GUI showing the next three rungs.
  • Hub + warps. Spawn, per-depth warps, a rank-gated warp menu.

Presentation — ship it now, not later

  • Scoreboard v1. Rank, balance, current depth, blocks this session — and one deliberately empty slot you'll fill with Din next phase. Built on the slot registry so nothing is hardcoded.
  • Nametags v1. Rank prefix above the head and in tab. Wire the gradient path now even though everything is a flat colour today — you'll thank yourself in phase 6.
  • Tab list. Header/footer with server name and online count. Two hours of work, makes the server feel real immediately.
  • Sell feedback. An actual animated total with a sound, not a grey chat line. This is the first thing that will make it feel like a server rather than a plugin.

Gate

A brand-new player reaches D5 without asking a single question. Watch someone do it and don't help.

Playable

Yes, and dull. Do not add features to fix that — phase 2 is the fix.

Scope · 2–3 weeks · mostly a port from Shadow Prison

02Vertical
slice
If this isn't fun, stop and fix it — nothing after it matters

The Din

Prove the core loop. One meter, one faction, one question: does anyone voluntarily stay in danger for money?

Systems

  • Din float per player. Accrual on break (base 1.0 × enchant modifiers × AoE block count), decay 4/sec while not breaking.
  • Five thresholds with hysteresis. 120 / 400 / 900 / 1800, and a 5% deadband on each boundary so the bossbar doesn't flicker and the audio doesn't stutter.
  • Sell multiplier stamped at break time into the item's PDC. ×1.0 quiet → ×4.0 CHOIR. Never at sell time.
  • Spawn pressure hook. Din band → spawn rate and cap within the region. Superlinear between bands, not smooth.
  • Target-selection override. Every ~20 ticks, re-aim hostiles in range at the loudest player. Do not touch pathfinding. This is the whole "sound navigation" illusion and it's about forty lines.
  • The Listening. Ear, Crier (+150 Din on scream, broadcasts you 80 blocks), Lattice (splits into four, loudly), Long Quiet (can't perceive you at Din 0).

Presentation — this is where the server gets a soul

  • The Din bossbar. Colour ramps amber → red across bands, name changes to the band name, fill is per-band not global so each band feels like its own climb.
  • Audio is the most important work in this phase. Layered ambient that adds a track per band. At SWARM, a heartbeat under everything. At CHOIR, cut the ambient out for half a second before the new layer starts — silence lands harder than noise.
  • Screen effects via resource pack shader: a faint vignette from DRAWN, creeping desaturation at CHOIR.
  • Scoreboard. Fill the empty slot — a live Din readout with a mini bar built from unicode block characters, coloured by band.
  • Threshold crossings in chat, personal only, colour-coded, one short line. Never a number — colour and words, per your own law.
  • Nametag. A player at SWARM or above is visibly marked to other players nearby. Danger should be legible across a room.

Gate — the only one that really matters

Six people play three sessions. Somebody voluntarily camps SWARM for the money, and somebody else calls them insane. If nobody does, your multiplier curve is too flat or your spawn pressure is too brutal. Fix that and nothing else until it's true.

Playable

This is the game. Everything after this is depth, identity and reasons to stay.

Scope · 3–4 weeks · then live with it for a month before phase 3

03Home

The Rigs

Give players something above the fog that's theirs, and something they can lose.

Systems

  • Rig claims on a visible grid over the fog. Tiers 16×16 → 96×96 bought with Salt. Build protection, trust list, expansion that preserves builds.
  • The perimeter. Lamp posts consuming Pitch, burn rate scaled by footprint, mob-spawn suppression inside a lit ring. Expanding permanently raises upkeep.
  • Pitch as a mined resource with its own drop table in the deeper Depths.
  • The fog layer beneath the rig grid — a hard visual floor so the world reads as bottomless.

Presentation

  • Perimeter lamp colour — your first sellable cosmetic, and the flagship. Build the colour/gradient engine properly here: solid hex, multi-stop gradients, animated phase. Everything later reuses it.
  • Rig silhouettes and light shafts through fog at night. This is the shot people screenshot. Spend real time on it.
  • Scoreboard. Pitch remaining as a time value ("4h 12m"), and perimeter status as a colour-coded LIT / DARK.
  • Chat + title warning when your perimeter drops under an hour — escalating, and it should be genuinely alarming at ten minutes.
  • Join message reflects your rig's state. Coming online to "your lamps went out six hours ago" is a whole story in one line.

Gate

Somebody lets their perimeter go dark for the first time, loses something, and tells everyone about it. That's the mechanic working.

Playable

Mine, sell, rank, and keep a home lit. The first real money sink is live.

Scope · 3 weeks

04Biggest
phase

Room Heat & The Wanting

Make the map something that changes on its own. Build it in this exact order — the order is the advice.

Systems — sequenced deliberately

  • 1 · Heat as a number, logged only. One float per region, deposited on break, decayed at −200/hr. Ship nothing visible. Just log it and watch where your server actually goes for two full weeks.
  • 2 · Read the logs. Tune deposit and decay against real behaviour, not against your intuition. You will be wrong about where people mine.
  • 3 · Four states + behaviour. Cold / Warm / Hot / Warren. Disperse-delay scaling with heat; ambient spawns at Hot and above regardless of Din.
  • 4 · The Wanting. The same AI code path with heat substituted for din as the target input, plus one new rule: don't disperse while the room is warm. A second faction, not a second system.
  • 5 · The Warmth. Reads on thermal exactly like a rig lamp. It's a heat source, so it cooks the room it stands in — it lures you and takes your mine.
  • 6 · Warren nests as generated structures, plus named spawns at that tier.

Presentation

  • STEAM. Ship this before the payout multiplier. Haze at Warm, plumes at Hot, a doorway breathing white at Warren. Players must be able to read a room before you start paying them to gamble on one.
  • Thermal goggles — a resource-pack shader item that renders heat sources, including the Warmth, exactly like a lamp. The item that makes the lie work.
  • Scoreboard. Current room state, colour-coded, with the Warren state animated so it's impossible to miss.
  • Warren entry warning. A full-width animated gradient title. This is the moment to show off the colour engine you built in phase 3.
  • The /heat map. A GUI rendering nearby regions by state. Players will plan rotations in it and it will become the most-used command in the game.

Gate

Two weeks of logs show players rotating between shafts rather than camping one. If they're still camping, decay is too fast or the payout is too flat. Do not proceed on a hunch — read the logs.

Playable

The map has a life of its own. Players start keeping private shaft lists and lying about them.

Scope · 4–5 weeks · the single biggest phase in the plan

05The
fusion

The Seal

Join the two meters. One dial, three consequences, and the first real build divergence.

Systems

  • Seal integer 0–100 on the suit, set at a workbench, changeable in the field.
  • Three multipliers driven off it: Din, body heat, and room heat deposit. Sealed 0.35 / 2.10 / 0.4 · Open 1.90 / 0.40 / 2.2.
  • Field toggle. Four seconds standing still, and it dumps a spike of whatever you were holding — a bang when you crack, a heat surge into the room when you seal.
  • Ore lanes. Rimeveined (shatters warm → forces Open → cooks its own shaft), slagstone (needs heat → forces Sealed), hush-glass (fractures above 400 Din → no escape hatch), emberite (heats you as you cut it).
  • The assert, in a unit test: din_mult × body_heat_mult ≥ 0.74 at every seal position after every enchant combination. If both meters can be floored at once, the fusion is dead. Somebody finds that combination in week three and it should be you.

Presentation

  • Seal state on the player model — armour trim or overlay, readable at a glance from across a room. You should be able to look at someone and know their lane.
  • Nametag seal icon, sealed cyan / open amber, matching the HUD.
  • Two bars, amber over cyan. Din on top because it moves fastest.
  • The four-second toggle gets a real animation, a mechanical sound, and a visible burst on completion. It's a commitment — make it feel like one.

Gate

Your test group splits into sealed-mains and open-mains and argues about which is correct. If everyone converges on one seal position, the multipliers are wrong.

Playable

Builds diverge. The first metas appear. Crews start assigning roles.

Scope · 2–3 weeks

06Self-
policing

PvP, Bounties & The Wake

Make griefing into content instead of a moderator ticket — and use the nastiest punishment in the game as your nametag showcase.

Systems

  • PvP zones. Rigs and D1–D9 safe — new players are never anyone's prey. D10+ (the Crossing onward) live. Warrens always live, no exceptions.
  • Bounties. /bounty, same-gang kills pay nothing, visible on scoreboard and nametag.
  • Breaching Charges. Craftable, genuinely expensive, consumed on use. You cannot flood casually — a vandal has to fund every shaft they drown.
  • Flooding. Heat to zero, nest drowns, all unmined ore in the region lost.
  • The Wake. 6h per breach, stacking, ticking only while online so it's served in public. Wake I–V. PvP-flagged everywhere including spawn and their own rig — the punishment is exile from safety, not removal.
  • Server-matched bounties on Wake players, scaling with level. On death the payout splits: killer takes the largest share, the rest is auto-distributed to every player who had heat in the shafts they drowned. Restitution without a ticket.
  • /restitution — pay it back directly, clear the Wake early.
  • /flooded — permanent public breach log. Who, when, which shaft, what was lost. Forever.
  • The Drowned Watch at Wake VIII+. Named hostiles that spawn on that player specifically, anywhere, until it clears. The in-fiction ban.

Presentation — the nametag and RGB showcase

  • The WAKE nametag. An animated dripping gradient, deepening from Wake I to Wake V, per-character phase offset so it genuinely flows. This is your flagship nametag effect — and the joke is that it's a punishment that looks incredible. Everything you learn building it goes straight into the paid cosmetics in phase 9.
  • Water particle trail on Wake players. You can hear and see one coming.
  • Scoreboard. Bounty on your own head in animated red; nearest Wake player's distance if you're hunting.
  • Breach announcements server-wide, naming the shaft and the player, with the colour deepening at higher Wake.
  • Bounty claim gets a full server broadcast with a proper title card. These should feel like events, because they are.

Gate

Somebody hits Wake III and the server organises a hunt with no moderator involved. That's the whole system working.

Playable

The server polices itself, pays its own victims, and gets a recurring event out of its worst players.

Scope · 3 weeks

07Depth

Prestige, Skills & Enchants

A reason to still be here after D26.

Systems

  • Cold Depths C1–C30. Prestige. Same 1.09× ladder multiplier and cost curve as Shadow Prison — it's tuned, don't re-derive it.
  • Skills. Mining, Smelting, Selling, Acrobatics, plus Nerve — XP for time spent above DRAWN, perks that reduce Din generation and shorten the Wanting's lock.
  • Enchant ladder with dinPerProc and heatPerProc on every entry. Two floats retune all 54 across both channels at once.
  • Hush I–V (−Din, +heat) and Vent I–V (−heat, +Din) as the two ends of one enchant line you can't run both of.
  • Teeth (Listening) and Rime (Wanting) as split named-mob currencies, and the Bone Market mutations: Deaf, Hollow Lungs, Chorded — each with a real downside.

Presentation

  • Prestige badges in nametag and tab, with the gradient engine finally doing what it was built for.
  • Mutations have visual tells. A Deaf player looks different, and other players learn to read builds on sight.
  • Skill level-up — a proper animated title, sound, and particle. Small moments, constantly.
  • Prestige ceremony broadcast server-wide. Losing everything should be witnessed.

Gate

Your first player prestiges voluntarily, and a second one does it because they watched the first.

Playable

Long-term progression. The server has a top end.

Scope · 4 weeks

08Endgame

The Climb & The Ledger

An ascension that changes the shape of the game, and a world that remembers a year of habits.

Systems

  • The Listening Post — a server-funded orbital tether built off the tallest rig. Everyone contributes, everyone can see the progress bar, and it takes weeks.
  • Ascension inverts the game. Above the fog there's no air — so Din is dead (the bar greys out permanently) and heat cannot shed (no convection, radiation only, and only while standing perfectly still doing nothing). The two-meter game collapses into the half you can't escape.
  • The signal answers you personally, by name, in chat, on your own blocks — with a unique message format nobody else's messages use.
  • The Ledger. Lifetime traffic per region, never fully clearing, raising a permanent ambient Din floor. Walk into a year-old shaft already at STIRRING.
  • Residents. Past a Ledger threshold, something named is living in it — grown out of nothing but your server's own habits, killable, and worth arguing about whether to take early or let get fat.
  • Events: the Night Shift (perimeters drain 4× server-wide), Choir Runs (4-player co-op, payout scales with how fast you hit CHOIR), Salvage Dives.

Presentation

  • The ascension ceremony. Every player on the server sees it. This is the single biggest set-piece in the game — build it like one.
  • The [LP#] nametag in white-bold, and a permanent light visible from the rigs below.
  • Silence above the fog. No ambient track at all. After a year of layered dread, the absence is the effect.
  • The Night Shift gets a server-wide bossbar, a countdown, and a dawn broadcast listing who stayed lit.

Gate

Someone ascends and says the silence up there is worse. That's the design landing.

Playable

Complete game, start to finish.

Scope · 4 weeks

09Identity

Cosmetics & RGB

The only thing anyone ever pays for — and by now you've already built most of the engine.

Systems

  • Roles. A paid ladder that grants strictly cosmetic and convenience perks. Nothing touches Din, heat, yield or safety. Ever.
  • /nick, /titles, /chatcolor, wings, trails, auras, hat, sit, vault slots.
  • Perimeter lamp cosmetics — the flagship, from phase 3, now monetised. Every neighbour across the fog sees it every night, forever.

Presentation — this phase is presentation

  • The RGB chat theme engine. A custom core text-shader override in the resource pack so gradients genuinely move, per character, in chat and on nametags. 100+ themes across motion and effect categories. You already have this working in Shadow Prison — port it, don't rewrite it.
  • Wings as particle art rendered from per-shape pixel grids, with flap animation.
  • Animated nametags — everything the Wake taught you, now for sale.
  • Join messages, custom per role, and a proper title card on entry.

Gate

A player who has never bought anything on any server buys a lamp colour because they saw someone else's across the fog.

Playable

The server has a face and a business model.

Scope · 4–5 weeks · largely a port

10Control

The Dials

Never edit a config file again.

Systems

  • /config — every dial in the plugin, in a chest GUI, with test buttons and exact-value inputs. If you registered as you went, this phase is mostly layout.
  • /adminset <player> — one GUI to edit everything about one player.
  • Economy watch, dupe audit, /playerlog, /testdrops, /invbackup, maintenance mode.
  • A Din/heat live inspector — see any player's meters and any region's state in real time. You will use this more than every other admin tool combined.

Presentation

  • Admin GUIs get the same care as player GUIs. You're going to live in these for years.

Gate

Retune the entire Din curve from in-game, during a live session, without a restart — and watch the effect land immediately.

Playable

Everything, and now you can steer it.

The honest total Roughly eight to ten months solo at a sustainable pace, and phases 0–2 are about seven weeks of that. Which is the good news: you find out whether the whole idea works in under two months, and if the phase 2 gate doesn't pass, you've spent seven weeks instead of a year. Do not build ahead of the gates.
And one rule for the whole plan Every phase ships something a player can see. Not because it's efficient — it isn't — but because a server that looks like vanilla Minecraft for eight months has nobody left to show the finished version to.
