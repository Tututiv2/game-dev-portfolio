# SkyClone vs the real game: mechanics audit (2026-10-06)

Audit only, no code changed. Source of truth: `SkyblockMoney/work/*.md` (fresh research on live Hypixel SkyBlock,
2026-10-06; wiki + NEU/SkyHanni repos + official changelogs). Each research fact was looked up in
`plugin/src/main/java/com/skyclone/mod/<module>/`, `plugin/src/main/resources/data/<module>/` and
`docs/handoff/<module>.md`.

Severity: **econ** = economy-breaking · **gate** = progression gate · **drop** = drop-table value · **cosm** = cosmetic.
Fix size: S (data/dial edit) · M (one module, new logic) · L (new subsystem / several files).

Sections are appended as each research file is finished (kuudra, mining, combat, fishing, farming_passive, then the
optional ones if present).

The level gates, recipes, requirements and most slayer/fishing tables were generated from the NEU/SkyHanni repos and
are right. What is wrong clusters in three places: **(1) the Kuudra chest is the pre-June-2025 model** (no Tentacle,
Fatal Tempo ~170x too common, prestige-tier armour drops, no guaranteed Kraken/teeth/essence, faction rep sources at a
third of real); **(2) the pest economy** (pest crop drop ~15x too small, no 15% rare crops), which in the real game is two
thirds of Garden income; **(3) mining RNG tables** (Crystal Nucleus, worms/Scatha, Mining Fiesta 2x drops at the old
BP/2,000 rate). Whole systems absent: Sowdust, Moby-Duck / Pearl of the Swamp, Green Bandana item, Experimentation-Table
ultra-rare pool, Kuudra rep-per-day and the Emissary key discount, Shellwise netting (made fusion-only).

### Top 10 fixes (impact first)
1. **G1** garden: pest crop drop = `base + FF/scale` enchanted crops per pest type (ours ~15x low).
2. **K1-K3** kuudra: add Kuudra Tentacle (weight 16), real slot-2 weights; Fatal Tempo / Inferno 0.02-0.38 not 3.75%.
3. **K9** kuudra: chests drop Basic-tier armour only (no HOT_/BURNING_/FIERY_/INFERNAL_ prefixes).
4. **K5-K8** kuudra: guaranteed Kraken 1/1/2/2/3 + Teeth 1/1/2/2/3 + paid essence; free essence 10/25/50/100/200.
5. **M9** mining: Crystal Nucleus 14-19 rolls + fine-gem set + 800 HOTM XP, Divan's Alloy 0.09%/bundle, no Apparatus self-drop.
6. **G2** garden: 15% pest rare crop per pest (13 items already registered).
7. **K13 + K16 + K17 + K18** crimson: quest rep 30/50/75/100/125, Kuudra +10..50 rep once/day/tier, Emissary key discount, Rollim.
8. **M3 + M4** mining/mayors: Mining Fiesta = +25% fortune / +25 wisdom, BP/10,000, whole term, minister-eligible.
9. **M5 + M7 + M8** mining: worm 1/600 hard-stone-only with 30 s cooldown; Scatha 4 membrane + Fine Topaz, pets 0.24/0.12/0.04%; chest 1/500, 4.5 rolls.
10. **F1** fishing: regenerate sea-creature Fishing XP from the post-2025-03-18 values (Sea Walker 150, ...).
