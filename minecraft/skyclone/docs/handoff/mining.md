   prediction; the client keeps sending arm swings while holding attack (abort after 6 silent ticks); a new
   START_DESTROY arrives when the crosshair moves. If digging never progresses, check `/sb mining block <p>`
   (table, speed, ticks) and `/sb mining regen` (active digs); `/sb dial set mining.engine false` falls back
   to vanilla breaking + the BreakHandler so mining still pays out.

   blocks are simply not mineable (never a crash). `/sb mining block` tells you which table entry a block hit.

   BEFORE its arm swing (the client sends use/drop first). If right-clicks ever break instamine blocks, that
   order is the suspect; `/sb dial set mining.engine false` still falls back to vanilla breaking.

   reasonable feel, not taken from the research; dials exist for all of them.
