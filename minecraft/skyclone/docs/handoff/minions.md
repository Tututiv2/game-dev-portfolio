# minions — hand-off

Package `com.skyclone.mod.minions`, entry `MinionsModule`. Data in `resources/data/minions/`, generated by
`py -3 tools/gen/minions/gen_minions.py` (never hand-edit the JSON; `tools/gen/minions/report.txt` lists every
override, synthesis and disagreement). Profile data: SHARED key **`minions`** (`MinionStore`) — the island,
its minions, slots and unique crafts belong to the co-op (research 05 co-op table).

| file | contents |
|---|---|
| `items.json` | 843 ItemDefs: all **719 minion tiers** (61 types x I..XI/XII, unique, skull per tier) + 124 owned items: 18 upgrades, 2 hoppers, 5 storage chests + X-pender, 8 fuels + Hyper Catalyst Upgrade, 15 Inferno fuels, 6 crystals, **5 Beacons (I-V)**, Mithril Infusion, 11 tier XII upgrade stones, 51 minion skins |

## Review pass (2026-10-02, second agent)

A reviewer read the whole module against CONTRACT, CORE_GUIDE, the API and research 02 section 4, then fixed what it
found. Verified the same way as the first pass: `bash tools/check.sh minions` -> **CHECK OK**, **20 JUnit tests
pass** (2 new), **8 self-tests** (1 new). Still never run on a server or clicked by a client.

Bugs fixed:
- **Offline catch-up could be wiped on login** (`MinionManager.tick`): the first tick after a member logs in ran the
  whole offline gap through the LIVE layout check, so a minion whose 5x5 was blocked produced nothing for the entire
  gap, and a Solar Panel counted the whole gap as daytime. Research 4.7: offline assumes a perfect layout and no
  sun. Now any gap longer than a tick period is advanced first with `live=false`, unpaused, and only the last period
  is live.
- **Soulflow Engines lost ~80% of their output** (`MinionSim.advance`): the per-second drop (1 Raw Soulflow per
  30/15 min) was only added on ticks that also completed a harvest; most 5 s ticks complete none. Timed outputs now
  accrue with time. Test `timedOutputAccruesWithTimeNotHarvests` (720 x 5 s ticks = exactly 2).
- **Collect All dumped items on the floor**: space was computed per item type, so every type counted the same empty
  slots. `MinionManager.InvSpace` now reserves space as it promises it (Collect All, Collect From All, pick-up).
- **Picking a minion up with a full inventory poured up to ~1,700 items on the ground** (owned for 60 s, then
  anyone's). Pick-up now refuses with a message unless the minion, its attachments and its storage all fit
  (`fitsPickup`); the admin `pickup` still forces.
- **Piston and explosion exploits**: a piston could push a Diamond Minion's ore out of its recorded spot, and breaking
  it there paid a real diamond; an explosion (BUILD zones allow them) dropped minion blocks as items. Pistons that
  would move a minion block are cancelled and explosions skip minion blocks.
- **A player's own block could stop dropping**: when a minion harvested its block the spot was never removed from
  the global protection index, so a block a player later placed there broke with no drop. `breakVisual` un-indexes.
- **Storage clicks re-validate**: handlers run a tick later and production can reshuffle storage; a storage click
  now only collects if the slot still holds the item the player clicked (`MinionMenus.sameSlot`).
- **Crystals menu**: Go Back was overwritten by Close (both slot 31 in a 4-row menu); crystals could be picked up
  from anywhere. Both fixed (pick-up needs the same on-island rule as minions, and room in the inventory).
- **Compaction hardened**: compacting now snapshots storage and backs off instead of "remove, then try to put back
  what did not fit". A 2,000-case randomised invariant test (`compactionNeverLosesItems`: stored after + overflow ==
  stored before + delivered) passes on both the old and new code, so no loss was reproducible; it is a guard.
- Rate-limit map is cleared on quit; crafted tiers glow in the per-type menu.

Breadth added:
- **Beacons I-V + Power Crystals** (research 02 section 4.6). `BEACON_1..5` were referenced by mining's Forge and the
  crafting recipes but registered by nobody; minions now registers them (DEPLOYABLE, unique, `requirements: hotm:N`
  from the NEU lore) plus Beacon I's crafting recipe (Mithril IX). One Beacon per island, placed like a crystal;
  while a **Power Crystal** (48 h, registered by materials) runs it, every minion on the island gets +2/4/6/8/10%;
  a **Scorched Power Crystal** adds +1%. Power belongs to the island (`MinionStore.beaconPoweredUntil`), drains in
  real time including offline, and survives swapping Beacon tiers. Offline catch-up splits at the exact moment the
  power runs out (`MinionManager.advance`), so a 3-day gap only gets 48 h of boost. Menus: **Beacon** (click the
  Beacon or `/minions beacon`: tier, boost, power left, click a Power Crystal in your inventory to insert it, pick
  up), the crystals menu shows the 5 tiers and the power, the overview header shows Beacon status. Self-test
  `minions.beacons` checks the data and runs the split (2 h with 1 h of Beacon III power = 264 harvests).
  Not built: the Beacon's profile-stat buffs (reference: "+20% profile stats" on Scorched) — minion speed only.

## What works (verified how)

Verified: `bash tools/check.sh minions` -> **CHECK OK**; **18 JUnit tests pass**
(`plugin/src/test/java/com/skyclone/mod/minions/MinionSimTest.java`, run with plain javac + the JUnit launcher;
they load the SHIPPED JSON). The dev server was NOT started (integrator's job) — everything Bukkit-side is
compiled against 26.1.2 and covered by the 7 self-tests and the RCON admin tools below. **Not clicked by a real
client yet.**

- **Production model** (`MinionSim`, pure, unit tested): one harvest every `2 x TBA`, speed bonuses add and divide
  the TBA, multiplier fuels multiply drops without touching speed, timed fuel burns in real time (offline too)
  and only powers the seconds it had left, infinite fuels, Solar Panel only by day while live. Fractional drops
  (Rabbit's Foot 0.35, Diamond Spreading 1/10) accumulate exactly — deterministic, no RNG. Research numbers come
  out of the data: Cobblestone I 14 s -> 128.57/h, slot table 0->5 ... 650->26, SB XP I-VI 1 ... XII 24.
- **Offline catch-up**: the same step runs a 5 s live tick and a 30-day catch-up (test: 100k+ harvests in < 2 s).
  A profile with nobody online is frozen and catches up from `lastUpdate` when a member logs in, bounded by storage
  (+ chest), overflow sold by a hopper. A login summary says what was made ("While you were away ...").
- **Storage**: tier slots (storage/64) + attached chest (3/9/15/21/27), per-item stack sizes (pearls 16),
  Compactor / Ultra Compactor (chains: Snowball -> Snow Block -> Enchanted Snow Block) / Deepdelver (smelt + compact),
  Auto Smelter, Budget (50%) and Enchanted (70%) Hopper selling overflow at NPC price into held coins.
- **All 61 types, every tier**: farming crops + animals, all ores, combat mobs, slayer minions (Ghoul, Broodweaver,
  Void Wraith, Inferno with "Rising Heat" +18%/minion up to 180% and the 15 Inferno fuels: x10/x15/x20 output with
  4/5 replaced by the specialty, hypergolic rare extras), 6 trees + Flower, Fishing, Clay, Lily Pad (the 61st).
- **Upgrades**: 20 upgrades with type/category/kind restrictions (Flint Shovel = Gravel only, Corrupt Soil = mob
  minions, Dayswitch/Nightswitch/Thorny Vines, Enchanted Egg/Shears...), one-per-island limits (Potato Spreading,
  Drowsy Hollow, Krampus Helmet), slayer requirements (Flycatcher = Spider 6, Soulstream = Enderman 2/5),
  Minion Expander (+1 radius, +5%), Mithril Infusion (permanent +10%, survives pick-up and tier upgrades),
  tier XII upgrade stones (from the minion menu or crafted), 51 skins (change the head).
- **External boosts**: island crystals (Farm/Woodcutting/Mithril/Winter/Cornucopia/Postcard — placed on the island
  like the modern reference, island-wide), matching pets (level x 0.3%, TUNE dial), Potato Talisman/Ring, mayor
  perks `cole.prospection` (+25% mining) and `derpy.turbo_minions` (x2 output), a global speed/output dial.
- **In the world**: a small armour stand with the tier's head, leather armour in the type's colour and a tool that
  improves with tier (wood -> diamond). Near a player it visibly works its 5x5 (7x7/9x9 with expanders): places and
  mines its block, tills and plants crops (cactus only with room, sugar cane by water, sunflower both halves), grows
  2-log trees with persistent leaves, spawns AI-less invulnerable mobs (max 2, dial) and slays them, splashes water
  or floats lily pads. Status bubble: "My storage is full! :(" / "This location isn't perfect! :(".
  While live, a minion with no usable cell pauses (reference); offline assumes a perfect layout (research 4.7).
- **Anti-exploit**: every block a minion places is recorded (`Placed.visuals`, persisted): breaking one drops
  nothing, popped crops (unowned item spawns of crop materials only), crop growth and mushroom spread around minion
  blocks are cancelled; minion mobs never drop (eggs, wool, milk, shears all blocked); stands are locked and
  invulnerable; pick-up removes the minion from data BEFORE giving anything; collection only takes what fits in
  the inventory; every menu action re-reads the shared data; installing an upgrade consumes it first.
- **Collection & XP**: collected items go through `Sky.loot().give(..., MINION)` (collections count them, sacks may
  absorb); skill XP per item from `xp.json` is split between co-op members, offline shares paid on their next login
  (research 4.7). Pick-up items come back as `STORAGE` (no collection credit, like the reference). Hopper sales
  give coins only.
- **Unique crafts & slots**: every new (type, tier) obtained by CRAFT or NPC_SHOP (`ItemGain`) or Quick Upgrade /
  upgrade stone counts once per profile, pays SkyBlock XP (`minion:<TYPE>:<tier>`, research table) and may unlock a
  slot (genre box "MINION SLOT UNLOCKED"). Slots = research table + Community Shop (`cshop:minion_slots:N`) + dial,
  capped at 31. Starter: new profiles receive a Cobblestone Minion I.
- **Menus** (all with Close, Go Back, `&eClick to ...!` hints, live refresh every second):
  - **Minion** (click the minion): info head, Ideal Layout, Quick Upgrade (shows TBA/storage before -> after,
    every ingredient with have/need, takes from inventory then sacks, all-or-nothing with refund), speed breakdown
    (every source labelled), production per hour + "full in X", status, infusion, storage summary, skin/fuel/
    shipping/2 upgrades/chest slots (click an item IN YOUR INVENTORY to install it; click the slot to take it out;
    timed fuel asks before burning away), 15 storage slots (locked ones say which tier unlocks them), chest view,
    held coins, island bonuses, Collect All, Recipes, Pick Up (confirm, warns about fuel).
  - **Your Minions** (`/minions`): every placed minion with status/storage/fuel/upgrades/location, slots header,
    Collect From All, Crafted Minions, Minion Slots, Fuels & Upgrades, Island Crystals, back to the SkyBlock Menu.
  - **Crafted Minions** (`/craftedminions`, also the Collections menu's button): 61 types with crafted tiers
    coloured, per-hour rates, unlock state, category filter; per-type page with all tiers (TBA, storage, rates,
    recipe cost, crafted?) -> click opens `/recipe`.
  - **Minion Slots**: the 22-tier table with progress bars. **Fuels & Upgrades** guide. **Island Crystals**.
  - **Ideal Layout**: the 5x5 around the minion, each cell green/red with what is there and what it needs.
- **Requirement resolver** `minion`: `minion:<TYPE>:<tier>` (crafted), `minion:uniques:<n>`, `minion:slots:<n>`.
- **Tab widget** `minions` (160): placed/slots, how many are full. **Objective** `place_minion` completed on placement.

## Known risks

1. **Live behaviour unverified**: armour-stand clicks (`PlayerInteractAtEntityEvent`), the per-player inventory-click
   install flow, and block/mob animations have never run in a client. If the menu does not open on click, the
   `/minions` overview still opens every minion when the player is on the island.
2. **Physics around decorative blocks**: popped crops are cancelled only for unowned item spawns of crop materials at
   minion-placed positions; an unusual neighbour update could still drop a vanilla plant item (low value). Diamond
   ore and other valuables are protected because breaking a recorded minion block drops nothing.
3. **Recipe dependencies on other modules**: only Magma Bucket, Plasma Bucket and Everburning Flame still wait (on
   `HEAT_CORE`); nothing breaks, `/sb minions recipes` lists exactly what is waiting.
4. **Pick-up now refuses with a full inventory** (it used to dump everything on the floor). If playtesters find that
   annoying, the alternative is to give what fits and leave the rest in the minion - not to drop it.
5. **Beacon ownership**: if mining later registers `BEACON_1..5` itself, core keeps the FIRST registration (whichever
   module enables first); the behaviour lives here and only reads the ids, so either works.
6. **Bonus radius**: crystals and the Beacon work island-wide (reference: radii of 8-140 blocks,
   which the Beacon's already covers). A deliberately tiny-radius crystal layout cannot be reproduced.
