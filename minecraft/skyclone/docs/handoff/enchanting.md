# enchanting — hand-off

Package `com.skyclone.mod.enchanting` (entry `EnchantingModule`), data `plugin/src/main/resources/data/enchanting/`,
generator `tools/gen/enchanting/gen_enchanting.py` (re-run it; never hand-edit the JSON), unit tests
`plugin/src/test/java/com/skyclone/mod/enchanting/EnchantingPureTest.java`.

## What works (verified how)

Verified by `bash tools/check.sh enchanting` (**CHECK OK**) and **13/13 JUnit tests** run against the SHIPPING data
files (javac + the JUnit launcher from the gradle cache; the integrator's `gradlew build` runs the same class).
**Not run on the live server** (no dev server for module agents): the 7 self-tests below are what to run first.

### Data (generated, not typed)
- **155 enchantments** = every enchanted book in `neu-repo/items/*;N.json` minus Telekinesis (auto-pickup is default,
  research 08 §3.2). Per level: values (parsed from the book text, research 01 §14 overrides where the 2026 numbers
  differ: Sharpness VII 50%, Titan Killer, Bane, Harvesting, Efficiency VI-X, Flame), rarity, table cost
  (`constants/enchants.json`), table max, item types (pools + the books' "Applied To"), conflicts (pools + research
  01 §14.2 groups), Enchanting skill level that unlocks it (research 02 road, 98 enchants gated), Experimentation
  sources, level-by-use thresholds (Champion, Toxophilite, Compact, Cultivating, Absorb, Expertise, Hecatomb).
- Descriptions are OUR wording (`DESC` in the generator). 12 proper nouns renamed (docs/names/enchanting.md).
- Each enchant is registered with core (`registerEnchant`) so item lore renders it; core gets the series-0 value.
- **Alias enchant ids** (`aliases` in enchants.json, 51 of them, generated by `add_aliases()`): each enchant also
  answers to its reference name and our name snake-cased, and ultimates to their id without `ultimate_`
  (`woodsplitter`->`arcane`, `pyroclasm`->`magmarizer`, `drain`->`syphon`, `bank`->`ultimate_bank`,
  `dragon_tracer`->`aiming`...). Reason: the skills table names its Enchanting unlocks by NAME (34 of its 98 didn't
  match our reference-game ids, failing `skills.unlock-enchants-exist`). Each alias is registered with core as its own
  EnchantDef (same data, alias id), so `Sky.items().enchant("bank")` resolves; `EnchantRegistry.spec()` resolves them
  too (admin commands accept `bank`). An alias never shadows a real id and never belongs to two enchants (generator
  aborts). Book items exist ONLY under canonical ids (`parseBook` is strict). Any item that carries an alias KEY in
  `ItemData.enchants` is rewritten to the canonical id on inventory close / profile ready (effects read canonical
  ids), higher level winning a clash. Note `Sky.items().enchants()` now lists 155 + 51 defs; anyone counting
  enchants should use the enchanting registry, not that collection.

### Items (owned here)
- **Enchanted books: one stackable item per enchant level**, 835 of them, id `ENCHANTMENT_<ENCHANT>_<LEVEL>` (= the
  Bazaar product id, tag `bazaar`) + an alias `<ENCHANT>;<LEVEL>` (= the id the research NPC shops and drop tables
  use, tag `enchanting_alias`). Aliases are converted to the canonical id on `ItemGain` and on inventory close /
  profile ready (dial). Book lore: "Combinable in Anvil", the enchant + its numbers, ultimate note, "Applied To",
  skill requirement; rarity per level.
- `ENCHANTED_BOOK` (unique, enchants in `ItemData.enchants`) is accepted by the anvil too (for modules that want
  multi-enchant loot books).
- `EXP_BOTTLE` (vanilla, throwable), `GRAND_/TITANIC_/COLOSSAL_EXP_BOTTLE` (right-click: 1,250 / 5,000 / 20,000 exp,
  dials, TUNE), `EXPERIMENTATION_TABLE` (placeable head, recipe at Enchanting X), recipes for Grand/Titanic bottles.

## What is partial / not built
- **Data only, effect expected from the owning module** (they read `Sky.items().data(stack).enchant(id)` and
  `Sky.items().enchant(id).value(level)`). Already done by their owners: fishing (Lure, Quick Bite, Caster, Blessing,
  Charm, Corruption, Frail, Flash in `fishing/Casting`), farming Turbo-* (`farming/Crop`) and Dedication
  (`farming/Harvest`), mining Silk Touch / Smelting Touch (`mining/Breaker`), foraging Efficiency (`foraging/Chopper`)
  and - since wave 4/5 - **Karma** (`foraging/MarshTrees`), **Missile** (`foraging/HotfAbilities`), **Petal Shower**
  (`foraging/Hotf`), dungeons' Hecatomb S-run counter (`dungeons/loot/RewardChests`, levelled here).
  Done HERE in wave 5 through other modules' existing hooks: Green Thumb, Bug Blender, Paleontologist (fallback),
  Scuba (requirement key), Stealth. **Still open (no hook anywhere):** Feast, Sunset's day part and Crop Fever's
  "+15" (no Overbloom stat), Sunset's night part (no garden visitor-cooldown hook), Dread / `great_spook` (no Fear stat).
  **Built in by design, no work needed**: Replenish (farming regrows every crop it handles) and Delicate (farming
  already refuses immature crops).
- **Vitality is a module-local pool** (core has none - core-wave5 "Not done"). Only abilities listed in the cost dials
  spend it; a module that adds a new healing ability must add its id to `enchanting.vitality.costs` (or ask). The
  pool is not saved (full on join / after death) and does not stop regenerating under Ward Veil (the reference does).
- **Scuba has no hazard to resist yet**: Pressure Resistance is published as requirement `pressure_resistance:N`; no
  zone gates on it until galatea builds the Spring Depths (request 17). Accessories' `extra.otherStats`
  PRESSURE_RESISTANCE and the HotF perk are not summed (neither is a runtime stat).
- **Simplified**: Soul Eater stores the killed mob's `MobDef.damage` (book text) and applies it as Strength with the
  research's 5k cap; First Impression's "first log of a tree" is "first log of a streak"; Looting/Luck/Chance are an
  extra roll rather than a multiplied chance (same expectation); Chimera copies the "pets" stat provider's flat
  numbers; Lapidary's Mining Speed applies while the block in your crosshair (6 blocks) is stained glass; Crop Fever's
  extra rolls are a 5% (dial) chance per crop for the enchanted form; Paleontologist rolls its bonus share itself
  (does not tick mining's scrap counters/commissions); Bug Blender applies while the vacuum is held.
- Experimentation numbers that research marks (?) are TUNE: base clicks per tier, XP per pair/round, reward weights,
  bottle experience amounts, anvil cost formula. Stealth radius / hold / re-roll seconds are TUNE (no research).
- **Item-lore descriptions show ONE number** until core calls `EnchantDef.describe(level)` (Request 1 - a 3-line core
  patch; every enchant already registers a `LevelledEnchantDef` that implements it, so nothing changes here when core
  does). Books, the guide and the table already show every number at full precision.
- **Book levels above the reference's books** (Drain VI, Scuba VI) are tagged `bazaar` like every other book, so the
  bazaar's catalogue lists them as products; drop the tag in `EnchantRegistry.bookDef` if the reference does not.

## Known risks
1. **Never run live.** The biggest unknowns are integration assumptions: that `DamageContext.weapon` is the bow for
   PROJECTILE hits (Power/Snipe/Chance), that `MobKill.combatXp` is set before HIGH priority, and that the anvil /

   the aliases needs a code change (the dial only turns off the conversion).
3. **Vanilla attribute modifiers** (Respiration, Depth Strider, Aqua Affinity, Feather Falling) are written to the
   player and persist in player data; they are recomputed every second, but if the plugin is removed they stay.
   Potato books are also applied by this anvil: if the reforges module applies them too the caps still hold
   (both use `ItemData.potatoBooks`, max 10 + 5).

4. **(wave 5) Vitality now gates healing abilities** other modules own. If a wand/orb/flare feels broken in a
   playtest, check `/vitality` first; `enchanting.vitality.enforce false` keeps the spending without the refusal,
   `enchanting.vitality.pool false` turns the whole pool off (Drain then heals % max HP again).
5. **(wave 5) Stealth toggles `Mob#setAware`** on creatures other modules spawn. Every calm is undone on expiry, on
   disable and on chunk load (tag `skyclone_calm`), but a module that itself relies on `setAware(false)` is left
   alone only if its creature was already unaware when the roll happened.
